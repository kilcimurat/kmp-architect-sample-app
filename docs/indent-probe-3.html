Three Ways to Indent an Imported Code Block

Line breaks survive as break tags. Indentation is the remaining question. The indentation of a snippet is not decoration: in Kotlin it is how a reader sees which lambda a statement belongs to. A code block that keeps its line breaks but loses its indentation is only half imported.
