A Smaller Build

A Kotlin Multiplatform architecture whose goal is module-level build isolation: a developer working on one feature builds and runs only that feature, on Android and iOS, and a Gradle gate proves it rather than a diagram claiming it.

Developed in a private codebase of 62 Gradle modules across 11 features. This repository is the three-feature reference implementation extracted from it, and every number in the series is reproducible here.

  1. Part 1 Your Feature Should Not Need Your App to Build Build isolation as the goal, layering as the means, and the numbers that say whether it worked.
  2. Part 2 Folder Shape Is Not Evidence Making a Gradle build prove that a KMP feature is isolated — on Android and iOS.
  3. Part 3 Auditable MVI Separating Action, Event and Effect, and making the separation a build failure instead of a code-review habit.
