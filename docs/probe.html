Code block import probe

Four ways of emitting the same snippet, to find which one survives an import.

A — pre + code, raw newlines

fun sampleFeedModules(): List<Module> = listOf(
    module {
        single<FeedRepository> { FakeFeedRepository() }
    },
)

B — pre + code, br tags and nbsp indent

fun sampleFeedModules(): List<Module> = listOf(
    module {
        single<FeedRepository> { FakeFeedRepository() }
    },
)

C — pre only, raw newlines

fun sampleFeedModules(): List<Module> = listOf(
    module {
        single<FeedRepository> { FakeFeedRepository() }
    },
)

D — pre + code, div per line

fun sampleFeedModules(): List<Module> = listOf(
    module {
        single<FeedRepository> { FakeFeedRepository() }
    },
)

End of probe.
